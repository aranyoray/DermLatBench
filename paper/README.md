# IEEE URTC paper draft

The paper is written against a **single source of truth**: `metrics.json`
produced by an audit run. Every headline number in `main.tex` is a
`\newcommand` macro from `numbers.tex`, which is regenerated by

```bash
dermlat-audit build-paper --output /path/to/private-results
```

That command drops `numbers.tex`, `tables/*.tex`, and copies the figures
from `<output>/figures/` into `<output>/paper/figures/`. The paper never
drifts from the audit.

## Building the PDF

Run the audit first, then:

```bash
cd /path/to/private-results/paper
latexmk -pdf main.tex
```

You need `latexmk`, `pdflatex`, and `bibtex` (any modern TeX Live works).

## Recommended pre-submission workflow

1. Run the full audit end-to-end on the real DermLatBench:
   ```bash
   dermlat-audit run --images /path/to/DermLatBench/images \
                     --annotations /path/to/annotations.csv \
                     --output /path/to/private-results
   ```
2. Run the injection-validation harness (needed for §IV of the paper):
   ```bash
   dermlat-audit validate-injections --images /path/to/DermLatBench/images \
                                     --annotations /path/to/annotations.csv \
                                     --output /path/to/private-results \
                                     --n-flips 200 --n-duplicates 200
   ```
3. Run the adversarial-blinding experiment (needed for the inflation table):
   ```bash
   dermlat-audit adversarial-blinding --images /path/to/DermLatBench/images \
                                       --annotations /path/to/annotations.csv \
                                       --output /path/to/private-results
   ```
4. Rebuild figures + numbers.tex + tables/*.tex from the resulting metrics:
   ```bash
   dermlat-audit build-paper --output /path/to/private-results
   ```
5. Build the PDF:
   ```bash
   cd /path/to/private-results/paper && latexmk -pdf main.tex
   ```

## What's checked into the repo

- `main.tex` — the paper template (never contains raw numbers).
- `refs.bib` — bibliography.
- `README.md` — this file.

`numbers.tex`, `tables/`, and `figures/` are generated per-run and are
gitignored under any `paths.output_dir`.
